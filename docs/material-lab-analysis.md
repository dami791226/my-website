# Material Lab 与试衣网站适配

## 源项目

- 仓库：https://github.com/nonglihong515-jpg/wuxiang-material-lab
- 已阅读 README、LICENSE、源码 zip 中的 app/page.tsx、lib/effects.ts、构建脚本及独立 HTML。
- React/TypeScript 负责工作台，Canvas 实现 15 种视觉特效；智能抠图使用浏览器端 IMG.LY Background Removal 1.7.0，纯色抠图使用边缘连通算法。
- 支持上传、粘贴、拖入、画笔擦除与恢复、撤销、PNG 和 16 格总览导出。
- 该项目不包含人体姿态估计、服装形变、尺寸推荐或 AI 换衣模型，不能直接当作真实试衣引擎。

## 已适配

保留当前试衣间与 5 张模特底图，在服装选择处增加素材工作台。复用上游 Canvas 算法，增加服装导入、去背景、边缘修整、效果调整、透明 PNG/总览导出；素材可回填原换衣接口，也能在模特图上做平面叠加、位置/宽度/旋转/透明度调整并导出。

原图效果为默认值，以保留商品颜色、版型。印刷与故障等特效只用于宣传素材，不能用于判断真实面料。平面搭配不模拟遮挡、褶皱或真实尺码，界面明确标注。

## 部署和数据

全部新增功能可在 GitHub Pages 静态环境运行，无需图片 API 密钥。智能抠图需联网下载模型；下载失败保留原图，可取消、重试或改用纯色抠图。图片不上传到模型资源主机。真实 AI 换衣仍使用现有服务端接口，尚未在 Pages 部署后端。

上游代码为 AGPL-3.0-only，已保留 LICENSE、源码、构建脚本和致谢。公开页面提供完整源码入口。密钥、测试图片、构建输出及临时参考源码不提交到 GitHub。
