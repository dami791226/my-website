# Material Lab Adaptation

This version of the fitting studio incorporates Material Lab code and is distributed under AGPL-3.0-only. See LICENSE. Local changes dated 2026-10-30: garment preparation UI, integration with fitting images, flat composition controls and export, static deployment support.

- Upstream: https://github.com/nonglihong515-jpg/wuxiang-material-lab
- Copyright (C) 2026 Material Lab contributors.
- `vendor/material-lab/effects.ts` is the original Canvas effects source. `effects.js` is generated by stripping TypeScript types. No effect algorithms have been changed.
- Application source: https://github.com/dami791226/my-website
- Optional AI cutout: IMG.LY Background Removal JS 1.7.0, Copyright IMG.LY GmbH, AGPL-3.0. Source: https://github.com/imgly/background-removal-js . Runtime and model data download on demand from esm.sh and staticimgly.com; image processing runs in the browser.
- Node.js 24 is required to rebuild the vendored JavaScript with `node scripts/build-material-effects.js`. End users need only a modern browser.

The upstream apple sample and application bundle are not included in this adaptation. Existing model images were supplied by the site owner; licensing of source code does not grant additional rights to photographs or model likenesses.
