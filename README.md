# 试衣间 · 一键换衣预览

一个快速体验线上虚拟试衣的网页原型：选择不同身材的模特、选择或上传服装，再生成上身预览。

## 快速体验

1. 安装 Node.js 20 或更新版本。
2. 在本目录运行 `node server.js`。
3. 在浏览器打开 `http://127.0.0.1:8000`。

网页可以在没有密钥的情况下打开、浏览示例模特和服装。真正生成 AI 试穿图需要图片服务商支持 OpenAI 风格的图片编辑接口，并在 `.env.local` 配置服务密钥：

```text
XJ_IMAGE_API_KEY=在本机填写服务商密钥
```

服务密钥只由本地 Node 服务读取，不能填写进 `app.js`、HTML 或公开网页。`.env.local` 已加入 Git 忽略列表。

## 最小验证计划

1. 准备 3 张不同身材的正面人物照片和 5 张清晰服装商品图。
2. 用 1 张人物图和 1 张服装图验证服务商是否支持多张图片参考编辑。
3. 检查人物身份、服装颜色与版型、不同姿态下的效果，再调整提示词。
4. 结果稳定后再添加商品库存、方案保存、顾客分享和正式部署。

预设照片用于界面演示。没有服务密钥或图片编辑模型能力时，网页不会伪造 AI 生成结果。

## 预设模特

用户提供的 5 张原图保存在 `assets/models/model-01.jpg` 至 `model-05.jpg`，按提供顺序编号。人物原图保持完整，未修改水印；未提供身高或尺码数据，因此不标注猜测尺寸。选择模特后，生成请求使用该编号对应的图片。

## GitHub Pages

公开网址：https://dami791226.github.io/my-website/

`main` 分支保留项目源码，`gh-pages` 分支托管静态页面。运行 `node scripts/build-pages.js` 生成 `dist/`，将其中内容发布至 `gh-pages`，Pages 来源设为该分支根目录。

GitHub Pages 不运行 Node 服务，因此线上可选择模特、上传图片作本地预览，但不能调用 AI 换衣。公开版本会明确提示此限制，且不会提交生成请求。本地 `node server.js` 仍保留原有生成接口。真实出图需要另行部署后端。

构建仅复制前端文件和 `assets/`；服务端、`.env.local`、访问令牌和测试输出不会被发布到静态网站。上传照片不会保存到 GitHub 仓库。
